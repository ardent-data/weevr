# Diagnostics API

The `weevr.diagnostics` module holds the diagnostic record every config
problem is reported as, the code registry, and the removed-key table. For
what each code means, see [Diagnostic Codes](../diagnostics.md); for how
errors carry diagnostics, see [Errors](errors.md).

::: weevr.diagnostics
    options:
      members: true
      show_root_heading: true
      show_source: false

::: weevr.diagnostics.removed_keys
    options:
      members: true
      show_root_heading: true
      show_source: false
